# Image Collection Checklist

## Goal
Collect public/licensed actor images for the image recognition Part 2 workflow.

## Actor Classes
1. Brad Pitt
2. Denzel Washington
3. Johnny Depp
4. Keanu Reeves
5. Leonardo DiCaprio
6. Morgan Freeman
7. Robert Downey Jr.
8. Samuel L. Jackson
9. Tom Hanks
10. Will Smith

## Dataset Target
- 100+ images per actor
- At least 1,000 total images
- Include different lighting, angles, ages, facial expressions, and backgrounds
- Include some images with multiple people for annotation practice

## Required Metadata
For each image, record:
- actor_name
- image_filename
- source_url
- license
- author
- notes

## Do Not Commit Large Image Files Yet
Store raw images locally first. Push only folder structure, README files, metadata files, scripts, and small documentation files unless Git LFS is configured.
